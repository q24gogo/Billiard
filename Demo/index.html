Q24-가브리엘당구클럽

카카오톡 안에서는 홈 화면에 추가할 수 없어요.
아래 버튼으로 크롬(안드로이드)이나 사파리(아이폰)에서 열어 주세요.

게임 리뷰

경기 전체를 다시 보기

    게임 코칭

    실패 샷의 원인 · 교정 · 추천

      📌 다음에 또 보려면 (홈 화면에 추가)

      🤖 안드로이드 폰

      1. 카톡에서 링크를 눌러 연 뒤, 오른쪽 위 ⋮ 를 누르고 "다른 브라우저로 열기" → 크롬(Chrome)을 고르세요.
      2. 크롬 오른쪽 위 ⋮ → "홈 화면에 추가" (또는 "앱 설치") → 추가.
      3. 홈 화면에 생긴 Q24 프리미엄 아이콘으로 언제든 다시 열 수 있어요.

      🍎 아이폰

      1. 카톡에서 링크를 눌러 연 뒤, 오른쪽 아래 ⋯ 또는 공유 버튼을 누르고 "Safari로 열기"를 고르세요.
      2. 사파리 아래쪽 공유 □↑ → "홈 화면에 추가" → 오른쪽 위 추가.
      3. 홈 화면에 생긴 Q24 프리미엄 아이콘으로 언제든 다시 열 수 있어요.
